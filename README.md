# MIT VNAV Robotics Integration Project

Solutions for the **MIT VNAV (Visual Navigation for Autonomous Vehicles)** course.

---

## About the Project

This repository contains coding solutions for the MIT VNAV course. The labs cover topics ranging from Linux/ROS environment setup to UAV motion planning and control, visual navigation, visual odometry, SLAM, and perception. Please refer to the official MIT VNAV course materials for the original assignment specifications and theoretical background

## Prerequisites

The project is primarily developed and tested on **Ubuntu 24.04** with the following dependencies:

* **OS:** Ubuntu 24.04 LTS
* **ROS:** ROS Jazzy
* **Languages:** C++14/17, Python 3.11
* **Build Tools:** CMake, Make, Catkin
